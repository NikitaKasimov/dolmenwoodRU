## ГОНЧИЕ (описание)

### 1. Ищейка (Bloodhound)

Средние гончие с гладкой рыжей шерстью и кроваво-красными глазами. Выведены за их превосходные навыки выслеживания. Обычные рабочие собаки, встречающиеся в каждой лесной деревне Дольменвуда.

**СРЕДНЕЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| | |
|---|---|
| **Уровень** | 2 |
| **КД** | 13 |
| **ХП** | 2к8 (9) |
| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+1, 1к6) |
| **Скорость** | 50 |
| **Мораль** | 7 |
| **ОО** | 20 |

**Выслеживание:** Превосходные ищейки по запаху. Как только ищейка встаёт на след, его чрезвычайно трудно сбить.

### 2. Даппер (Dapper)

Кудрявые собаки с огромными висячими ушами и длинной шерстью, закрывающей глаза. Дапперы предпочитаются знатными классами за их любопытную страсть наряжаться в нелепые одежды и исполнять забавные танцы.

**МАЛОЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| | |
|---|---|
| **Уровень** | 2 |
| **КД** | 13 |
| **ХП** | 2к8 (9) |
| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+1, 1к4) |
| **Скорость** | 50 |
| **Мораль** | 7 |
| **ОО** | 20 |

**Язык:** Дапперы способны имитировать речь. Каждая собака может быть обучена имитировать до 10 слов, хотя они не имеют ни малейшего представления об их значении.

### 3. Дольменский пинчер (Dolmen Pincher)

Гладкие, мускулистые охотничьи гончие с чёрной шерстью и рыжей мордой. Используются особенно для охоты на крупных зверей.

**СРЕДНЕЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| | |
|---|---|
| **Уровень** | 2 |
| **КД** | 12 |
| **ХП** | 2к8 (9) |
| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+1, 1к6 + сбить добычу) |
| **Скорость** | 50 |
| **Мораль** | 9 |
| **ОО** | 35 |

**Сбить добычу:** Если дольменский пинчер успешно атакует цель 4-го Уровня или ниже и выбрасывает 4 или выше на урон, он сбивает цель. В следующем Раунде цель не может двигаться и получает -1 к Классу Доспеха и Атаке.

### 4. Ланкстонский мастиф (Lankston Mastiff)

Огромные, массивные звери с густой, косматой шерстью и вспыльчивым, свирепым нравом. Мастифы — превосходные и прилежные сторожевые собаки, но они печально известны сложностью дрессировки.

**СРЕДНЕЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| | |
|---|---|
| **Уровень** | 3 |
| **КД** | 12 |
| **ХП** | 3к8 (13) |
| **Спасброски** | Рок 11, Луч 12, Оковы 13, Взрыв 14, Чары 15 |
| **Атаки** | Укус (+2, 1к6+1) |
| **Скорость** | 40 |
| **Мораль** | 9 |
| **ОО** | 40 |

**Проваленные Проверки Морали:** Если ланкстонский мастиф проваливает Проверку Морали, есть 2-из-6 шанс, что он взбесится, атакуя любого, кто приблизится к нему (включая владельца или дрессировщика). Это состояние постоянно.

### 5. Личхаунд (Lichhound)

Коренастые, серые гончие с проволочной шерстью, стоячими заострёнными ушами и узкими жёлтыми глазами. Личхаунды выведены Церковью как спутники для кладбищенских стражей и клириков ордена Святого Сигниса.

**МАЛОЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| | |
|---|---|
| **Уровень** | 1 |
| **КД** | 12 |
| **ХП** | 1к8 (4) |
| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+0, 1к4) или 1 изгоняющий лай |
| **Скорость** | 40 |
| **Мораль** | 8 |
| **ОО** | 10 |

**Не боится нежити:** Не проверяет Мораль в бою с чудовищами-нежитью.

**Изгоняющий лай (раз в день):** Личхаунд может издать лай, ужасающий для нежити. При броске 2к6 на 7 или больше нежить 1-го уровня изгоняется, а при броске 9 или больше — нежить 2-го уровня. Если лай успешен, 2к4 чудовища-нежити бегут от гончей на 1 Ход.

### 6. Пискер (Pisker)

Коренастые, коротконогие собаки с блестящей рыжей шерстью, высунутыми языками и мягкими, пухлыми животами. Известны своим игривым, буйным темпераментом и невыносимым тявканьем. Обычно содержатся народом Пригворта, который боится присутствия фей.

**МАЛОЕ ЖИВОТНОЕ — ЖИВОТНЫЙ ИНТЕЛЛЕКТ — НЕЙТРАЛЬНОЕ**

| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+1, 1к6) |
| **Скорость** | 40 |
| **Мораль** | 8 |
| **ОО** | 20 |

**Обнаружение фей:** Все животные проявляют беспокойство в присутствии фей. Однако у пискеров этот инстинкт отточен до совершенства. Пискер (даже спящий) может обнаружить фей в пределах 20' и даст знать об их присутствии, непрерывно тявкая в течение 1 Хода.

### 7. Сили-дог (Seele Dog)

Высокие, серебристошёрстные гончие с хрупким костяком и длинными ногами, приспособленными для бега. Глаза сили-догов ярко-розовые, и говорят, что они фейского происхождения.

**МАЛОЕ ЖИВОТНОЕ — ПОЛУРАЗУМНОЕ — НЕЙТРАЛЬНОЕ**

| | |

| **КД** | 13 |

| **Спасброски** | Рок 12, Луч 13, Оковы 14, Взрыв 15, Чары 16 |
| **Атаки** | Укус (+0, 1к4) |
| **Скорость** | 60 |
| **Мораль** | 7 |
| **ОО** | 10 |

**Язык:** Не могут говорить, но имеют базовое понимание языка (обычно вольдиш и сильван).

**Лояльность:** Сили печально известны своей разборчивостью в отношении компаньонов — есть только 2-из-6 шанс, что сили-дог привяжется к смертному владельцу. Если собака невзлюбит владельца, она будет совершенно упрямой. Если она полюбит владельца, она будет неизменно верной.

### 8. Спукхаунд (Spookhound)

Стройные, короткошёрстные гончие кроткого нрава, узнаваемые по бело-серой шерсти, пушистым хвостам и выпученным глазам. Спукхаунд был выведен для способности обнаруживать присутствие нежити.

## ПРИНАДЛЕЖНОСТИ (описание)

**Собачий доспех:** Лёгкий кожаный доспех с шипастым ошейником. Даёт +2 к Классу Доспеха.

**Корм:** Свежие мясные обрезки и кости для грызения. Собак также можно кормить пайками из свежедобытой дичи (см. «Поиск еды в дикой природе», стр. 152).
